</Card>

## Which release asset?

On [GitHub Releases](https://github.com/abhishek-verma/Pane/releases), look for tags like **`browser/v0.47.0.1`**.

| Asset | For |
|-------|-----|
| `Pane_v*_arm64.dmg` | Mac with Apple Silicon (M1/M2/M3/M4) |
| `Pane_v*_x64.dmg` | Intel Mac |
| `Pane_v*_x64_installer.exe` | Windows |
| `Pane_v*_x64.AppImage` | Linux (most distros) |

Do **not** download `pane-agent-*.crx` unless you are developing the extension. That file is for updates inside an already-installed browser.
